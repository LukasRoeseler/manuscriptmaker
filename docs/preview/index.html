    About this preview

    100% in your browser. Nothing is uploaded, and nothing is stored anywhere else. This is a layout preview: the authoritative PDF, JATS XML, and OJS package are produced by the GitHub Actions pipeline when you open a Pull Request (how to submit). Citations like [@key] resolve there, not here. The article body is directly editable, so click into it to fix anything. Word equations become live formulas, and code-styled paragraphs become code blocks. A PDF has no real structure to read, so its text is best-effort and its formulas show as images cropped from the page (not live equations); fix by hand, then use .docx export for a separate, fully editable copy (edits there don't flow back into the pipeline). Save for later keeps a draft in this browser only (IndexedDB), so you can close the tab and resume; clearing your browser data removes it, and it never leaves your machine.
